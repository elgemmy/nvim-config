# nvim-config

My personal Neovim setup. Minimal by intent. Only what I currently use

| | |
| --- | --- |
| **lazy.nvim** | plugin manager |
| **kanagawa** | colorscheme |
| **nvim-lspconfig** | LSP client setup |
| **none-ls** | formatting and diagnostics |
| **nvim-treesitter** | syntax highlighting |
| **telescope** | fuzzy finding |
| **neo-tree** | file explorer |
| **lualine** | statusline |
| **gitsigns / vim-fugitive** | git integration |

## Languages

LSP configured for: Lua, Python, TypeScript/JavaScript, C/C++, Rust.

## Usage

```bash
git clone git@github.com:elgemmy/nvim-config.git ~/.config/nvim
```
